Как перенести данные из одной Веб ГИС в другую
===============================================

С этой задачей часто сталкиваются клиенты, которые после тестирования функционала в облаке решают развернуть NextGIS Web на своём сервере.

Чтобы перенести данные, нужно выгрузить их на компьютер, а затем загрузить данные в новую Веб ГИС.

.. _backup_source:

Создание локальной копии данных на компьютере
-----------------------------------------------

Основной способ сделать это - при помощи модуля NextGIS Connect.
Создайте соединение с исходной Веб ГИС. Выберите нужные ресурсы или группы ресурсов в панели NextGIS Connect и нажмите **Добавить в QGIS**.

Если вам важно **перенести данные быстро**, можно выбрать Основную группу ресурсов, добавить её в QGIS, а дальше разбираться со структурой данных.

Если вам важно **сохранить структуру ресурсов**, то можно пойти по следующему алгоритму:

1. Добавить в QGIS **веб-карты** *и сохранить каждую в свой проект QGIS*. Вместе с ними сохранятся все добавленные на них слои и подложки.
2. Добавить в QGIS **группы ресурсов** с данными, не добавленными на веб-карты, в один общий проект. В нём слои также будут распределены по группам.

Структуру Веб ГИС вы можете получить в виде таблицы при помощи инструмента Toolbox `Структура Веб ГИС в таблицу <https://toolbox.nextgis.com/t/web_gis_structure>`_.

Какие ресурсы будут выгружены таким образом:

* Векторные слои со стилями
* Растровые слои со стилями
* Слои WFS, PostGIS, WMS, TMS
* Сервисы WFS, WMS, OGC API – Features
* Соединения TMS, WMS 
* Подложки
* Справочники - справочники сохраняются как виджет Карта значений, чтобы затем загрузить справочник в новую Веб ГИС, его нужно экспортировать в CSV и заново подключить в QGIS к нужному слою при помощи виджета Связанное значение (value relation)

Для того, чтобы добавить в QGIS несколько ресурсов сразу, выбирайте:

* Веб-карту - при добавлении в QGIS она будет представлена в виде проекта со слоями, стилями и подложками. Подложки карты будут объединены во взаимоисключающую группу;
* Демо-проект - в QGIS будет создан проект, содержащий слои, стили и подложки;
* Группу ресурсов - в текущий проект QGIS будет добавлена новая группа и входящие в неё ресурсы типов, указанных выше, в том числе веб-карты.

Нюанс: при добавлении веб-карты в проект добавляются также все входящие в неё слои, если вы добавляете группу, содержащую веб-карту, это может вызвать задвоение слоёв в проекте.

Загрузка данных в новую Веб ГИС
-----------------------------------

В модуле NextGIS Connect создайте новое подключение - к целевой Веб ГИС.

Откройте проект QGIS с сохранёнными локально данными.

В панели NextGIS Connect выберите, в какую группу ресурсов загружать данные, нажмите **Добавить в Веб ГИС**, выберите **Загрузить всё** и задайте название для новой группы ресурсов, которая будет создана для загружаемых слоёв.

При добавлении проекта целиком в этой папке будут созданы все слои проекта, распределённые по группам, а также одна веб-карта, включающая все эти слои.

Если при создании локальной копии вы сохранили несколько проектов, загрузку в новую Веб ГИС нужно будет произвести для каждого из них.

Большая часть ресурсов будет перенесена таким образом. Однако некоторые ресурсы привязаны к конкретной Веб ГИС и их нужно будет создать заново.

Какие ресурсы нужно создать вручную:

* Группы трекеров
* Трекеры
* Проекты Collector
* Набор тайлов
* Набор файлов
* Библиотека маркеров SVG - если вы использовали такую библиотеку, рекомендуем встроить значки в стиль слоя или файл проекта, сделать это можно при помощи инструмента Toolbox `Добавление SVG в QGS/QML <https://toolbox.nextgis.com/t/embedsvg>`_



Альтернативный способ выгрузки и загрузки данных при помощи инструментов Toolbox
-----------------------------------------------------------------------------------

Частично ресурсы можно перенести из одной Веб ГИС в другую без помощи настольного приложения, используя инструменты `Toolbox <https://toolbox.nextgis.com/?lang=ru&tags=10>`_.

Создание локальной копии данных: 

* `Веб-карта в проект QGIS <https://toolbox.nextgis.com/t/webmap2qgis>`_ - сохранит только те слои, которые добавлены на веб-карту.
* `Векторные слои из Веб ГИС в GeoPackage <https://toolbox.nextgis.com/t/ngw_to_gpkg>`_ - сохранит только векторные слои из выбранной папки.

Загрузка в Веб ГИС:

* `Векторные слои из архива в Веб ГИС <https://toolbox.nextgis.com/t/layers2ngw>`_
