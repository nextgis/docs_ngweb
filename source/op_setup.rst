Настройка
=========

.. important:: Все шаги в этом разделе должны выполняться с правами
   суперпользователя (``root``). Если вы используете ``sudo``, то чтобы
   не запутаться в командах, рекомендуется сначала выполнить ``sudo -i``
   для получения полноценной сессии суперпользователя.

.. _change_endpoint:

Изменение адресов точек подключения
-----------------------------------

Изменение адресов точек подключения может потребоваться в случае
изменения DNS-имени сервера, на котором развернута система, либо при
изменении настроек обратного прокси-сервера. Для изменения адресов точек
подключения необходимо внести изменения в файл ``docker-compose.yaml``,
расположенный в директории ``/srv/ngwdocker``, в секции ``x-shared`` и
перезапустить стек:

.. code:: bash

   $ cd /srv/ngwdocker
   $ nano docker-compose.yaml
   $ docker compose up -d


.. _journal:

Включение модуля Аудита
-----------------------

В переменных окружения нужно задать следующие значения:

.. code::

   NEXTGISWEB__AUDIT__FILE__ENABLED=true
   NEXTGISWEB__AUDIT__DBASE__ENABLED=true

.. _move_server:

Перенос на другой сервер
------------------------

Последовательность действий:

1. На **исходном сервере** создайте офлайн резервную копию согласно инструкции :ref:`Создание резервной копии <backup_offline_create>`.

2. На **новом сервере** выполните установку NextGIS Web согласно разделу :doc:`op_install`.

   .. important::

      Версия устанавливаемого экземпляра NextGIS Web должна совпадать с версией на исходном сервере. Восстановление резервной копии между разными версиями не поддерживается.

3. Скопируйте файл резервной копии на новый сервер, например::

.. code:: bash

   $ scp /var/lib/docker/volumes/ngwdocker_backup/_data/archivist-20260117-002345.tar.zst \
        root@new-server:/var/lib/docker/volumes/ngwdocker_backup/_data/

4. Восстановите данные из резервной копии согласно инструкции :ref:`Восстановление из резервной копии <backup_offline_restore>`.
