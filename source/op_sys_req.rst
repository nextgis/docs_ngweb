Системные требования
====================

Для установки NextGIS Web On-Premise потребуется физический или
виртуальный сервер на базе архитектуры x86_64 (amd64) с следующими
характеристиками:

==== =========== =============
\    Минимальные Рекомендуемые
==== =========== =============
CPU  4 ядра      8 ядер
RAM  8 GiB       16 GiB
Диск 250 GB SSD  500 GB SSD
==== =========== =============

Объем дискового пространства в первую очередь зависит от предполагаемого
объема данных, которые будут храниться в системе. Рекомендуется
использовать SSD или NVMe накопители для обеспечения большей
производительности. Тактовая частота процессора не имеет принципиального
значения, однако использования CPU с более высокой тактовой частотой
положительно сказывается на производительности системы, так как наиболее
ресурсоемкие задачи в NextGIS Web связаны со сжатием изображений при
просмотре карт.

На сервере должна быть установлена операционная система на базе Linux
позволяющая установить Docker Engine 23 или более свежей версии,
например:

-  Ubuntu LTS 24.04, 22.04
-  Debian 12, 11
-  CentOS Stream 11, 10
-  Astra Linux 1.8, 1.7
-  РЕД ОС 8, 7.3

В случае использования дистрибутива Linux отличного от перечисленных
выше, убедитесь, что версия ядра Linux на сервере не ниже 5.10, что
соответствует текущей LTS версии.

Во избежании конфликтов сервер не должен использоваться для решения
других задач: файловый или почтовый сервер, сервер PostGIS и т.д.

Для выполнения шагов описанных в данной инструкции потребуется доступ с
правами суперпользователя (``root``). Доступ к Интернету на этапе
установки и обновления не является обязательным, однако значительно
упрощает процесс установки и обновления.
